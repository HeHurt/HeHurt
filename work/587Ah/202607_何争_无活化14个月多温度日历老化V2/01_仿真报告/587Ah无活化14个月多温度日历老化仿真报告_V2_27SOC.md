# 587Ah无活化14个月多温度日历老化仿真报告(V2, 27% SOC)

## 1. 工况与方法

本次采用587Ah DFN老化模型和标定参数 `params587calander.py`，对0–50°C、5°C间隔的11个温度进行**27% SOC 无活化**存储仿真。每个温度分别建立1–14个月的独立算例，共154次。

与V1(50% SOC)相比，本版仅改变存储SOC，其余工况与流程完全一致。

所有算例共用同一个25°C基准状态：

1. 在25°C以0.5P恒功率充电至3.65V，再以0.5P放电至2.5V，得到基准容量C0 = 606.924Ah。
2. 再次充电，并以累计充入容量达到0.27×C0 = 163.870Ah作为终止条件，建立27% SOC存储初态。
3. 从同一基准状态分支，切换至目标温度并连续静置30–420天，中途不进行充放电。
4. 存储结束后回到25°C，静置1h。
5. 以0.5P放电得到保持容量；**保持率以0.27×C0为分母**。
6. 随后以0.5P充电至3.65V、再以0.5P放电至2.5V，得到恢复容量；恢复率以C0为分母。

0.5P按587Ah×3.2V×0.5换算为939.2W。老化加速因子固定为1。每次温度切换均重新创建 `pybamm.ParameterValues("OKane2022")` 并加载对应温度参数。

## 2. 标定参数

本轮使用25°C和45°C、50% SOC活化存储实测数据完成的SEI参数：

| 参数 | 标定值 |
|---|---:|
| EC diffusivity | 2.1×10⁻²² m²/s |
| SEI growth activation energy | 39000 J/mol（2026-08-07 由40000微调） |
| SEI kinetic rate constant | 4.8×10⁻¹⁵ m/s |
| Initial SEI thickness | 5×10⁻⁹ m，保持原值 |
| Negative electrode cracking rate | 保持原值 |

活化月度对标总体RMSE为0.52个百分点，其中25°C为0.19个百分点、45°C为0.71个百分点。

- 14个月恢复率在0°C基本一致；25°C几乎相同（差异+0.01pp）；
  50°C 27% SOC恢复率比50% SOC高0.21个百分点，即**低SOC下高温长时间存储的不可逆损失更小**。
- 保持率随SOC降低而分母变小，其绝对值不能直接与V1对比；可比口径为恢复率（分母均为C0）。

## 6. 主要结论

1. 27% SOC下保持率与恢复率均保持温度、时间单调性，无异常。
2. 14个月恢复率从0°C的99.21%下降至50°C的90.64%；高温加速效应明显。
3. 27% SOC相比50% SOC，在50°C/14个月时不可逆损失由9.58%降至9.36%（恢复率+0.21pp），低SOC存储对SEI主导副反应更温和。
4. 保持率分母为0.27×C0，反映27% SOC初态下的可用容量保持；恢复率分母为C0，反映全容量恢复能力，两者物理含义不同。
5. 当前参数由25°C和45°C、50% SOC活化存储恢复容量标定；27% SOC及0–20°C、30–40°C、50°C结果属于模型外推。
