# CW501 DFN 参数审计与模型对标报告

## 1. 结论

`paramsLDSCW501.py` 原始版本存在多项可由设计参数表直接确认的映射错误，不能原样用于 CW501/MIC CW500 的 DFN 建模。现已完成最小修正，并以 PyBaMM 26.4.2 搭建启用接触阻抗的 DFN，复现设计表配套实测文件中的全部恒功率充放电工况。

- 20 个仿真工况全部求解成功。
- 接触阻抗参数保留为 `9.0549e-05 Ω`，模型选项 `"contact resistance": "true"` 已显式开启。
- 25℃充/放电平均 RRMSE：0.579% / 0.834%。
- 45℃充/放电平均 RRMSE：0.488% / 1.023%。
- 5℃充/放电平均 RRMSE：1.130% / 1.668%。
- 当前主要偏差集中在 5℃放电，模型终止容量平均高估 4.27%；这属于低温动力学/传质参数的后续标定问题，不再是几何量级错误。

## 2. 参数审计与修正

设计参数来源：`仿真所需设计参数表模板-to位念-修改版.xlsx` → `仿真参数表` → `MIC CW 500` 列。

| PyBaMM 参数 | 原值 | 修正值 | 依据 |
|---|---:|---:|---|
| Nominal cell capacity [A.h] | 1300 | 1361.9 | 设计容量；实测满充容量约 1350–1363 Ah |
| Electrode height [m] | 0.557 | 0.555 | JR 极片长度 555 mm |
| Electrode width [m] | 52094 | 52.094 | `0.2135 m × 61 层 × 2 面 × 2 JR`；原式漏掉 mm→m |
| Positive electrode thickness [m] | 136.7e-6 | 135.7125e-6 | `(286.425 − 15) / 2 μm` |
| Negative electrode thickness [m] | 113e-6 | 113.525e-6 | `(232.05 − 5) / 2 μm` |
| Positive particle radius [m] | 0.55e-6 | 0.45e-6 | LFP Dv50 = 0.9 μm，按球形半径取 Dv50/2 |
| Negative particle radius [m] | 4.5e-6 | 5.5e-6 | 石墨 Dv50 = 11 μm，按球形半径取 Dv50/2 |

隔膜厚度 11 μm、极片层数、JR 数量及接触阻抗未发现需要修改的直接证据。孔隙率、活性物质体积分数、固相电导率、扩散系数、交换电流密度和初始化学计量比不能仅由这张设计表唯一确定，本轮保留现有标定值；它们仍属于后续参数辨识范围。

## 3. 模型和工况

- 模型：PyBaMM DFN。
- OCP：正负极均使用 `current sigmoid` 充放电 OCP。
- 接触阻抗：开启，`R_contact = 9.0549e-05 Ω`。
- 求解器：`IDAKLUSolver(rtol=1e-6, atol=1e-8)`。
- 网格：`x_n/x_s/x_p = 5/5/5`，`r_n/r_p = 20/20`。
- 初始状态：充电从 0% SOC，放电从 100% SOC。
- 截止电压：充电 3.65 V，放电 2.5 V。
- 输出周期：30 s。
- 实测功率：从每个工况两只 cell 的 `|V×I|` 中位数取均值，避免把 P-rate 误当作 C-rate。

覆盖工况：

- 25℃、45℃：0.125P、0.167P、0.334P、0.668P，分别充电和放电。
- 5℃：0.125P、0.167P，分别充电和放电。
- 每个工况保留两只实测电芯曲线；指标表同时给出逐 cell 结果和 `mean` 行。

## 4. 结果摘要

| 温度 | 方向 | 平均 RMSE [V] | 平均 RRMSE [%] | 终止容量平均偏差 [%] |
|---:|---|---:|---:|---:|
| 5℃ | 充电 | 0.0383 | 1.130 | -0.58 |
| 5℃ | 放电 | 0.0532 | 1.668 | +4.27 |
| 25℃ | 充电 | 0.0196 | 0.579 | +0.80 |
| 25℃ | 放电 | 0.0265 | 0.834 | -0.15 |
| 45℃ | 充电 | 0.0165 | 0.488 | +1.04 |
| 45℃ | 放电 | 0.0327 | 1.023 | +0.69 |

最差工况为 5℃、0.167P 放电：两只电芯平均 RRMSE 1.859%，终止容量高估 4.97%。25℃、0.668P 放电也出现较明显的倍率端偏差，平均 RRMSE 1.391%，终止容量低估 1.62%。

## 6. 后续建议

若需进一步收敛 5℃放电和高功率放电偏差，建议优先标定低温下的负极/正极交换电流密度、固相扩散系数和电解液传输参数，再评估接触阻抗是否需要温度依赖；不要再改动已由设计表锁定的几何参数。
