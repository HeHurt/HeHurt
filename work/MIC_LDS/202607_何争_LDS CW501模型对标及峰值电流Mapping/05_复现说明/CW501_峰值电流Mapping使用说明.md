# CW501 10s / 30s / 60s 峰值电流 Mapping 使用说明

## 计算范围

- 模型：PyBaMM DFN，接触阻抗已开启，`9.0549e-05 Ω`。
- 脉冲时间：10 s、30 s、60 s。
- 充电温度：0–55℃，5℃间隔。
- 放电温度：−30、−20、−10℃；0–55℃为5℃间隔。
- 充电 SOC：0–95%，5%间隔；放电 SOC：5–100%，5%间隔。
- 截止电压：充电 3.65 V，放电 2.5 V。
- 结果输出周期：2 s；IDAKLU 内部采用自适应积分并连续定位截止事件。
- 全量：81 个“方向×温度×脉宽”计算组、1620 个 SOC 结果点。

## 一键运行与自动导出

打开 `02_模型/CW501_10s30s60s峰值电流Mapping.ipynb`，在 Jupyter 或 VS Code 中选择“运行全部”。

Notebook 会自动：

1. 检查参数、接触阻抗、温度/SOC/脉宽矩阵。
2. 运行或续算完整峰值电流 Mapping。
3. 生成覆盖率、未求解点统计、热力图和温度切片图。
4. 全量结束后导出 `04_输出结果/峰值电流Mapping/CW501_10s30s60s峰值电流Mapping.xlsx`。

Excel 与 `Hithium_TI_314Ah Cell Pulse Power Map(5℃间隔)-20241024.xlsx` 采用相同主体布局：

- Sheet：`10s`、`30s`、`60s`。
- 每张 Sheet 上半区为放电、下半区为充电。
- 三个横向区块依次为脉冲电流 `(A)`、首时刻实际功率 `(W)`、DCR `(mΩ)`。
- 功率按 `|I × V_first|` 计算；DCR 按 OCV 与脉冲首时刻端电压之差计算。
- 负温充电与无定义的边界 SOC 单元格保持空白。

## 中断续算

检查点逐组写入：

`04_输出结果/峰值电流Mapping/peak_current_map_v3_checkpoint.txt`

该文件内容是标准 UTF-8 CSV，仅使用 `.txt` 扩展名规避 DLP 对反复覆盖 CSV 的文件锁。中断后重新运行 Notebook，会自动跳过已完成的完整组。
