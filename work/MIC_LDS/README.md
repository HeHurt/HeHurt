# MIC 目录说明

本目录用于存放 MIC 1175Ah 及1300Ah电芯相关的原始数据、循环对标、专题分析与历史遗留 notebook。

## 目录分区

### 1. 不同温度倍率循环
- 用途：循环寿命、欧盟电池法、倍率/温度循环对标
- 主要内容：
  - `45℃循环原始数据-0401_csv/`
  - `MIC_25C循环汇总.xlsx`
  - `MIC_CW363对标.ipynb`
  - `MIC多温度拟合.ipynb`
  - `MIC常规循环.ipynb`
  - `MIC常规循环_带干涸.ipynb`

### 2. 03-1175Ah电芯数据
- 用途：1175Ah 原始测试数据仓
- 主要内容：倍率充放电、工况放电、核容、静态 OCV 及转换后的 CSV

### 3. 数据分析
- 用途：处理后的汇总分析与对比图
- 主要内容：
  - `MIC_CW500_A1轮硬壳汇总.xlsx`
  - `MIC_宫士鼎数据处理.ipynb`
  - `processed_curves/`
  - `长时A2-2轮不同CW短期性能/`

### 4. 宫工-徐恒-不同CW
- 用途：历史 CW / 自放电 / 干涸相关工作区
- 说明：该目录包含 legacy 脚本与 notebook，新功能不要继续堆在这里
- 主要内容：
  - `Fun_NC.py`
  - `MIC_欧盟_legacy.ipynb`
  - `MIC_电解液干涸.ipynb`
  - 多个 `MIC cw*.ipynb` / `MICrate*.ipynb`

### 5. 段安冉-自放电率
- 用途：自放电专题分析

### 6. 长时储能峰值电流
- 用途：峰值电流 / 峰值功率地图导出

## 使用约定
- 新的 MIC 循环寿命或欧盟对标 notebook，优先放在 `不同温度倍率循环/`
- 新的汇总分析 notebook，优先放在 `数据分析/`
- 历史 notebook 若仅保留参考价值，放在原目录并标记 legacy，不再继续扩展
