# LDS CW368 DFN 参数审计、模型对标及产热功率报告

## 1. 输入数据与工况

- 设计参数来源：`仿真所需设计参数表模板-to位念-修改版.xlsx` 的 `LDS CW368` 列。
- 实测曲线：`CW368_00029_CH2_充放电曲线.csv`、`CW368_00030_CH1_充放电曲线.csv`。
- 温度：25℃。
- 实测功率：0.125P 约 627.91 W；0.25P 约 1255.81 W。
- 0.167P 目标功率约 838.88 W，文件夹内没有直接实测曲线，仅作模型预测。
- 实测温度通道均为 −200℃，表明热电偶未连接，因此本次不能直接对标温升或量热数据。

## 2. 参数固化

`paramsLDSCW368.py` 已固化以下 CW368 差异项：

- 设计容量：1362.4 Ah。
- 正极单面反弹后厚度：96.5125 μm。
- 负极单面反弹后厚度：80.45 μm。
- 隔膜厚度：11 μm。
- 正极粒径半径：0.45 μm；负极粒径半径：5.5 μm。
- 电极高度：0.555 m。
- 设计电极宽度：`0.2135 × 83 × 2 × 2 = 70.882 m`。
- 正极活性物质体积分数：0.67569，孔隙率：0.28681。
- 负极活性物质体积分数：0.68557，孔隙率：0.29118。
- 接触阻抗：`7.018e-5 Ω`，DFN 中已开启接触阻抗选项。

设计表没有动力学、扩散、OCP、熵热及热物性数据，这些项沿用现有海辰 LFP 参数基线。

电压曲线对标使用有效面积系数 `0.937`，将设计几何对应的理论可用容量校准到实测约 1214 Ah；产热计算关闭该校准，使用原始设计面积（面积系数 `1.0`）。充电初始 SOC 为 0.008，放电初始 SOC 为 0.995，用于对齐完整工况的初始电压和可用容量窗口。这些值是模型—实测对标设置，不是设计表原始参数。

### 2.1 负极 OCP 平台校准

初版模型直接使用通用 `Gr_charge.csv` / `Gr_discharge.csv`。模型伪 OCV 的石墨分级嵌锂主拐点位于约 0.68–0.75 SOC，实测位于约 0.58–0.60 SOC，说明问题主要是负极 OCP 的化学计量映射，而不是简单的倍率极化。

本版在 `paramsLDSCW368.py` 中固化了平滑、局部的负极 stoichiometry warp：

- 局部 warp 幅值：0.077714。
- 作用区间中心参数：0.212309–0.600000。
- 平滑参数：0.060111。
- 负极 OCP 电压偏置：−2.749 mV。

校准后，0.125P/0.25P 的主拐点分别移动到约 0.601/0.593 SOC，与实测约 0.595/0.578 SOC 接近。该校准同时约束两倍率、充放电四条曲线，不是对单条曲线逐点补偿。由于没有三电极或半电池 OCP 数据，它仍属于全电芯可辨识下的等效负极 OCP 校准。

## 3. DFN 与产热口径

模型采用 PyBaMM DFN：

- 接触阻抗：开启。
- OCP：正负极 current-sigmoid 充放电迟滞选择。
- 温度：25℃等温。
- 结果周期：30 s。
- 网格：`x_n/x_s/x_p=5`，`r_n/r_p=20`。
- 电压截止：充电 3.65 V、放电 2.5 V。
- 电压对标面积口径：有效面积系数 0.937。
- 产热面积口径：原始设计面积系数 1.0。

产热功率口径：

1. PyBaMM 电化学热源：欧姆热、不可逆反应热、可逆熵热和迟滞热。
2. 接触阻抗热：显式计算 `I²R_contact`。
3. 净总热：包含可逆热的正负号，可出现阶段性负值，代表熵效应造成净冷却。
4. 总发热量：将负的可逆热截为零后统计，用于观察不可逆发热负荷。

## 7. 结论与限制

1. CW368 参数文件已按设计表几何和结构固化，模型启用接触阻抗。
2. 负极 OCP 的中段化学计量映射是原平台错位的主因；平滑局部校准后，四组电压 RRMSE 均改善。
3. 0.167P 结果属于插值功率下的模型预测，没有直接实验验证。
4. 电压对标使用 0.937 有效面积系数，产热使用 1.0 原始设计面积，两套结果已在输出中分开标记。
5. 现有试验没有有效温度历程或量热结果，因此产热功率只能通过电压曲线间接约束，不能视为已完成热学实测对标。
6. 若后续补充三电极/半电池 OCP、低倍率静置 OCV、壳温、极耳温度或量热数据，应进一步拆分正负极 OCP、熵热系数和散热参数的贡献。
