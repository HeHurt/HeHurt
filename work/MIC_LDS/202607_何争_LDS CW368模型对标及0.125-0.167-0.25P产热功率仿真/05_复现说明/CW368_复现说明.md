# CW368 DFN 对标及产热功率复现说明

## 一键运行

打开：

`02_模型/CW368_DFN模型对标及产热功率仿真.ipynb`

在 Jupyter 或 VS Code 中执行“运行全部”。Notebook 默认加载已经完成的结果；需要重新运行六个 DFN 工况时，将 `FORCE_RERUN = False` 改为 `True`。

## 结果位置

`04_输出结果/CW368_DFN对标及产热/`

包含：

- `curves.csv`：实测、0.937 面积电压对标模型及 1.0 设计面积产热模型全过程。
- `metrics.csv`：逐电芯/循环及平均 RMSE、RRMSE、MAE、容量误差。
- `heat_summary.csv`：各产热组分的平均值、峰值和积分热量。
- `efficiency_summary.csv`：实测/模型能量效率。
- `config.json`：模型、工况、接触阻抗、初始 SOC 和网格设置。
- `run.log`：六个工况的运行记录。
- `plots/cw368_voltage_benchmark.png`：0.125P、0.25P 充放电曲线对标。
- `plots/cw368_heat_power.png`：0.125P、0.167P、0.25P 充放电产热功率。

## 重要说明

- 0.167P 没有直接实测曲线，只是模型预测。
- 实测温度通道为 −200℃，热电偶未连接；产热结果未直接进行温度/量热对标。
- `dfn_sim / benchmark_calibrated_area` 使用面积系数 0.937，仅用于电压曲线对标。
- `dfn_heat_design / heat_design_area` 使用面积系数 1.0，用于产热结果。
- 负极 OCP 含 CW368 专属的平滑局部 stoichiometry warp，用于修正石墨分级嵌锂平台位置。
- 模型使用等温热源计算，接触阻抗热单独按 `I²R` 加入。
