# 内置电解液储库 / 芯吸结构 - 查新风险初评

日期：2026-06-05  
范围：公开 web 初筛。未接入度衍官方 API，未覆盖未公开申请。结论用于工程选题与交底书撰写，不是正式 FTO 或法律意见。

## 拥挤度

**中-高。** 该方向不是空白：早期已有非锂体系的 reservoir + wicking system，也有锂离子二次电池内置补充电解液腔/渗出结构。仍可继续推进，但不能泛泛主张“内置储液腔 + 芯吸补液”。本案需要落在长时储能厚电芯、储库容量与寿命消耗匹配、芯吸路径与贫液热点匹配、释放速率与循环后期消耗匹配。

## 相近在先技术

1. [US20030162085A1](https://patents.google.com/patent/US20030162085A1/en) 公开了用于 nickel-zinc cell 的 reservoir space 与 absorptive material，吸液材料伸入储液空间形成电解液传输路径。该文件对“储库 + 芯吸”的宽概念很接近，但体系、场景和寿命定容判据不同。

2. [US20110200855](https://patents.justia.com/patent/20110200855) / [US8652668](https://patents.justia.com/patents-by-us-classification/137/260) 公开了锂离子二次电池内的补充非水电解液腔、泄漏孔/树脂密封件，并提到按容量下降趋势设计补液时机。该文件是本案最接近风险点。

3. [US20240030571](https://patents.justia.com/patent/20240030571) 公开了通过 pouch 功能孔进行电解液再注入的方法，属于外部再注液/返修路线，和本案内置被动储库不同。

4. [US20240113403](https://patents.justia.com/patent/20240113403) 公开了二次电池电解液注入系统，主要是制造设备/注液精度方向，不直接覆盖成品电芯内置储库。

## 新颖性影响

- 已公开：电解液储库、补充电解液、渗出/泄漏通道、吸液件/芯吸路径这些单点概念。
- 可争取：大容量长时储能电芯中，按目标寿命期电解液消耗量定容的被动储库；按端部/角部/厚度方向贫液热点布置芯吸路径；限流膜/毛细阻抗使补液集中在循环后期；储库结构与安全气隙、膨胀空间、壳体内压联动设计。

## 差异化建议

1. 主权利要求写成“三匹配”：储库容量匹配寿命期消耗量，芯吸路径匹配贫液热点，释放速率匹配后期消耗速率。
2. 不把储库限定在顶盖 cavity，否则容易落入 Sharp 的相近结构；优先写顶盖内侧、壳体侧壁、卷芯端面或角部非活性空间中的至少一种。
3. 芯吸结构不要只写“吸液材料”，要写多段毛细阻抗、端部/角部/厚度方向路径、非活性区接触、与焊接区/泄压通道隔离。
4. 技术效果聚焦万次循环后贫液/干涸、DCR 后期增长、容量 knee 延后，而不是短期浸润效率。
