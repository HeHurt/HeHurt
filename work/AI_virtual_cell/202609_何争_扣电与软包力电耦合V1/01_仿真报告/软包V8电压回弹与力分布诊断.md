# 软包 V8 电压回弹与力分布诊断

## 1. 结论

原 V8 模型的力学方向设置没有错误。该模型是二维截面，`x` 为电芯长度方向，`y` 为厚度方向；后处理图为了看清 154.5 μm 量级的叠层，将厚度方向大幅放大，因此外观呈现为细长竖条，但这不会改变实际求解方向。

旧回弹图的比较口径不成立：基线为“0 N + 关闭耦合 + 关闭呼吸”，耦合组为“100 N + 开启压力反馈 + 开启呼吸”，三个因素同时变化，不能把曲线差异单独归因于嵌锂呼吸。此外，旧判断比较的是最终静置电压绝对值，而不是从各自放电截止瞬间计算回弹幅度。

## 2. 100 N 载荷核验

- 加载面法向：`[nx, ny] = [0, 1]`，即厚度 `y` 方向；
- 加载边长：86 mm；
- 面外宽度：52 mm；
- 有效加载面积：`86 mm × 52 mm = 4472 mm²`；
- 名义压力：`100 N / 4472 mm² = 22.361 kPa`；
- 无呼吸时负极、隔膜和正极平均厚度压力均约 22.361 kPa，说明 100 N 换算和加载方向正确。

## 3. 为什么原力分布看起来奇怪

1. 厚度方向被放大，几何外观不是等比例显示；
2. 若显示 `solid.mises`，看到的是 von Mises 等效应力，不是用于孔隙率反馈的厚度压缩压力 `max(0,-solid.sy)`；
3. 有呼吸时石墨在高 SOC 膨胀，而 LFP 轻微收缩；各层使用完全粘结连续条件，因此差异应变会转化为自平衡界面应力；
4. 呼吸组在 SOC 90.4% 附近的厚度压力局部峰值为 362.97 kPa，但负极、隔膜、正极域平均压力分别约 73.78、22.36、33.65 kPa。局部峰值主要反映材料刚度/呼吸失配和端部效应，不能解释为外部 100 N 变成了更大的总力；
5. 判断孔隙率反馈宜使用域平均、P95/P99 或分层统计，不宜只看角点最大值。

## 4. 匹配后的电压回弹

两组均设置 `F_ext=100 N`、`coupling_on=1`、0.5C、0.13 Ah，只改变 `breathing_mode`：

| 指标 | 100 N 无呼吸 | 100 N 有呼吸 | 差异 |
|---|---:|---:|---:|
| 放电截止瞬间电压 | 2.48830 V | 2.45622 V | -32.09 mV |
| 静置末端电压 | 2.87489 V | 2.84782 V | -27.07 mV |
| 瞬时回弹 | 62.98 mV | 64.05 mV | +1.07 mV |
| 总回弹 | 386.59 mV | 391.60 mV | **+5.02 mV** |
| 放电容量 | 0.12836 Ah | 0.12849 Ah | +0.00012 Ah |

因此，软包开启呼吸后的静置电压绝对值虽然更低，但它的放电截止瞬间电压下降得更多；按正确的“静置电压－截止瞬间电压”定义，呼吸后的回弹幅度仍然更大，并不存在与扣电相反的趋势。
