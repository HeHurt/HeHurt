# 单层双侧出极耳软包：容量一致的 0.5C 全循环与扣电对比

## 1. 本轮修正

初始软包模型虽然已经把 Lithium-Ion Battery 的面外厚度设为 `52 mm`，但 1C 电流仍沿用扣电的面容量表达式。扣电参数中的等效涂层厚度为 `t_an=111.55 μm`、`t_ca=136.75 μm`，软包几何实际为石墨 `61.5 μm`、LFP `84 μm`，因此旧 `i_1C=0.2222 A` 与软包实际活性体积不一致。

旧工况的 0.5C 电流为 `0.1111 A`，而按软包几何重算：

```text
i_1C,pouch = min(ah_pos_soc1*L_pos/t_ca, ah_neg_soc1*L_neg/t_an)
            = 0.12797 A
I_0.5C     = 0.06398 A
```

旧工况实际约为 `0.868C`，所以 4200 s 左右电极平均嵌锂状态已经接近满充；先前图中的 59.3% 是用错误 `i_1C` 积分得到的容量比，不是电极真实 SOC。

V7 保留旧解作为诊断证据，另存容量一致的 baseline 和 100 N 耦合模型；后处理以正负极平均嵌锂窗口归一化后的电极 SOC 为主坐标，并同步保留库仑积分 SOC 做容量守恒检查。

电极状态 SOC 与库仑积分 SOC 仍相差约 3.2 个百分点，主要来自正负极实际几何容量不完全匹配以及截止事件处的容量窗口定义差异；该偏差已显著小于旧版 40.7 个百分点，但后续若做绝对容量标定，仍应统一 N/P 与 `i_1C,pouch` 的定义。

100 N 压力反馈和嵌锂呼吸对本工况的电性能影响很小：相对 baseline，充电容量变化小于 0.01%，库仑效率增加 0.044 个百分点，能量效率降低 0.086 个百分点。说明当前 0.5C 下，力学机制主要改变压力、孔隙率和位移场，并不是端电压或容量变化的主导项。

## 3. 扣电–软包对比

同为 0.5C、3.65 V/2.50 V、静置 600 s、外力 100 N、非线性呼吸：

| 指标 | 扣电 V9 | 软包 V7 | 软包相对扣电 |
|---|---:|---:|---:|
| 电极状态截止 SOC | 99.84% | 100.02% | +0.18 pct |
| 库仑效率 | 98.207% | 98.259% | +0.052 pct |
| 能量效率 | 95.666% | 96.041% | +0.375 pct |
| 峰值局部压力 | 320.68 kPa | 132.99 kPa | -58.5% |
| 石墨最大呼吸应变 | 4.985% | 6.350% | +1.365 pct |
| 厚度位移振幅 | 4.723 μm | 3.411 μm | -27.8% |
| 最大电解液浓度极差 | 889.19 mol/m³ | 174.01 mol/m³ | -80.4% |
| 50% SOC 集流体电流密度 P99 | 0.99 kA/m² | 307.61 kA/m² | 显著增大 |

主要机理判断：

1. 容量重标定后，扣电与软包的电压–SOC 曲线整体一致，说明 OCV、嵌锂方向和电化学参数迁移正确。
2. 软包极片更薄，因此同为 0.5C 时单位面积电流更低，电解液浓差明显小于扣电；这不是单纯几何形状造成，而是“几何厚度–容量–电流”共同变化的结果。
3. 软包长集流体到中心/端部极耳形成明显面内电流汇聚，集流体电流密度远高于扣电壳体；绝对值受两类导电区域定义不同影响，宜结合空间图判断热点位置，不应只用倍数做材料优劣结论。
4. 同为 100 N 并不等于同压力。软包受载面积更大，名义压力更低，因此其平均压力、孔隙率变化和厚度位移均小于扣电；若要单独比较几何，下一步应改用相同名义压力而不是相同总力。
5. 事件切换时出现的尖峰是隐式事件重初始化附近的瞬态输出点，不能解释为可持续的物理过压或负压；性能积分和空间场判断以事件前后稳定点为主。
