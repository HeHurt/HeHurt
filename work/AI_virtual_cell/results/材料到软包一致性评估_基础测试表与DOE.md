# 材料到软包一致性差异评估：基础测试表与 DOE

## 1. 项目目标与边界

目标是建立“材料粉体/极片/扣电/软包”四层数据闭环，判断不同型号材料在扣电中的 OCV、容量发挥、能效、阻抗等指标，能否定性或半定量预测软包性能，并识别扣电到软包差异的主要来源。

本项目不建议直接追求一个固定换算系数，例如“扣电容量乘某个系数等于软包容量”。更合理的输出是：

1. 建立扣电全电池对软包容量、能效、DCR、倍率性能的排序预测能力。
2. 分清材料本征差异、极片工艺差异、装配/浸润/化成差异分别贡献多少。
3. 给 P2D/DFN 模型提供可识别、可追溯的参数输入。
4. 形成后续材料筛选的最小测试包和升级测试包。

## 2. 样品与批次命名

建议统一命名，避免后续数据无法追溯。

| 层级 | 命名示例 | 说明 |
|---|---|---|
| 正极材料 | C0、C1、C2、C3、C4 | C0 为 reference，C1-C4 为候选正极 |
| 负极材料 | A0、A1、A2、A3 | A0 为 reference，A1-A3 为候选负极 |
| 极片批次 | C1-E01、A2-E01 | E 表示 electrode batch |
| 半电池 | C1-Li-HC01 | 正极/Li 或负极/Li 半电池 |
| 扣式全电池 | C1-A0-FC01 | full coin cell |
| 单层软包 | C1-A0-SP01 | single-layer pouch，作为扣电到软包桥梁 |
| 多层软包 | C1-A0-P01 | 正式软包 |

所有测试数据必须绑定材料批次、极片批次、电芯编号和测试设备编号。

## 3. 优先级定义

| 优先级 | 含义 | 使用场景 |
|---|---|---|
| P0 | 必测 | 建立扣电-软包相关性和基础 P2D 参数必须具备 |
| P1 | 建议测 | 增强追因和模型可识别性，适合首轮 DOE 中保留 |
| P2 | 异常追因或扩展 | 发现异常、要做安全/热/失效分析时再展开 |

半电池用于提取正负极 OCP、可逆容量、首效和材料动力学基础，不建议单独用半电池能效预测软包能效。

## 9. 首轮 DOE 总体设计

首轮 DOE 建议采用“单变量材料替换 + reference 校准”的方式，避免正负极全因子组合导致样本量爆炸。

### 9.1 DOE-I：材料型号主效应筛选

固定项：

- 固定电解液、隔膜、导电剂、粘结剂、涂布和化成制度。
- 固定目标面密度、压实密度、N/P 比和软包结构。
- 每一批都制作 C0-A0 reference，用于判断当天工艺漂移。

| 组合编号 | 正极 | 负极 | 目的 | 半电池 | 全电池扣电 | 单层软包 | 正式软包 |
|---|---|---|---|---:|---:|---:|---:|
| G0 | C0 | A0 | reference 基准 | C0/Li n=6；A0/Li n=6 | n=6 | n=3 | n=3 |
| G1 | C1 | A0 | 正极候选 1 主效应 | C1/Li n=6 | n=6 | n=3 | n=3 |
| G2 | C2 | A0 | 正极候选 2 主效应 | C2/Li n=6 | n=6 | n=3 | n=3 |
| G3 | C3 | A0 | 正极候选 3 主效应 | C3/Li n=6 | n=6 | n=3 | n=3 |
| G4 | C4 | A0 | 正极候选 4 主效应 | C4/Li n=6 | n=6 | n=3 | n=3 |
| G5 | C0 | A1 | 负极候选 1 主效应 | A1/Li n=6 | n=6 | n=3 | n=3 |
| G6 | C0 | A2 | 负极候选 2 主效应 | A2/Li n=6 | n=6 | n=3 | n=3 |
| G7 | C0 | A3 | 负极候选 3 主效应 | A3/Li n=6 | n=6 | n=3 | n=3 |

DOE-I 样本量：

| 类型 | 数量估算 |
|---|---:|
| 半电池 | G0 12 只 + G1-G7 各 6 只 = 54 只 |
| 全电池扣电 | 8 组 * 6 只 = 48 只 |
| 单层软包 | 8 组 * 3 只 = 24 只 |
| 正式软包 | 8 组 * 3 只 = 24 只 |

如果预算有限，正式软包可先只做 G0、G1-G4 或 G0 + 排名前 2 的候选；但全电池扣电不建议减少。

### 9.3 DOE-II：极片工艺敏感性桥接

DOE-I 后选择 reference G0 和 2 个代表性候选材料组合进入 DOE-II：

- 一个扣电和软包表现一致的组合。
- 一个扣电和软包偏差明显的组合。

## 10. 推荐电化学工步

### 10.1 Formation

| 步骤 | 建议 |
|---|---|
| 静置 | 装配后静置 6-12 h，软包按浸润制度执行 |
| 首圈充电 | 0.05C 或项目化成倍率，至上限电压 |
| 恒压 | 至电流降到 C/50 或项目标准 |
| 静置 | 30 min 或项目标准 |
| 首圈放电 | 0.05C 或项目化成倍率，至下限电压 |
| 重复 | 2-3 圈 |

Formation 输出 ICE、首圈不可逆容量、平均电压、初始能效和异常产气/厚度。

### 10.2 低倍率 OCV/容量

| 步骤 | 建议 |
|---|---|
| 倍率 | C/20 或 0.05C |
| 静置 | 充放电前后至少 2 h；若做准 OCV 可延长 |
| 输出 | Qchg、Qdis、Echg、Edis、平均电压、dQ/dV、OCV-SOC |

### 10.3 倍率测试

| 倍率 | 测试建议 |
|---|---|
| 0.1C | 基础容量参考 |
| 0.33C | 贴近中等倍率 |
| 0.5C | 能效和极化评价 |
| 1C | 放大动力学/传输差异 |
| 2C | P1，仅体系允许时 |

每个倍率至少 2 圈，取稳定圈；倍率之间可插入 0.1C 恢复圈。

### 10.4 EIS

| 条件 | 建议 |
|---|---|
| SOC | 20%、50%、80% 为 P0；10%、90% 为 P1 |
| 温度 | 25 degC 为 P0；10/45 degC 为 P1 |
| 频率 | 100 kHz 到 10 mHz，至少到 10 mHz |
| 扰动 | 5-10 mV |
| 输出 | Rohm、Rct、Warburg/CPE、拟合残差 |

### 10.5 DCR/HPPC

| 条件 | 建议 |
|---|---|
| SOC | 20%、50%、80% 为 P0；10%、90% 为 P1 |
| 脉冲 | 10s 和 30s 充/放电脉冲 |
| 倍率 | 按软包目标功率换算到扣电面积电流密度 |
| 输出 | 充电 DCR、放电 DCR、瞬时压降、恢复电压 |

## 11. P2D 参数与测试来源映射

| P2D 参数 | 主要来源 | 辅助校准 |
|---|---|---|
| 正极 OCP | 正极/Li 半电池 C/20 或 GITT | 全电池低倍率 dQ/dV |
| 负极 OCP | 负极/Li 半电池 C/20 或 GITT | 全电池低倍率 dQ/dV |

| 固相扩散系数 | GITT、倍率数据 | EIS 低频区 |
| 反应速率常数 | EIS Rct、倍率曲线 | DCR/HPPC |

## 12. 评价指标与判定标准

| 指标 | 计算/输出 | 目标用途 |
|---|---|---|
| 扣电-软包容量偏差 | Q_pouch - Q_coin_full | 判断容量映射误差 |
| 扣电-软包能效偏差 | EE_pouch - EE_coin_full | 判断极化/阻抗差异 |
| 排名一致性 | Spearman/Kendall | 判断扣电是否能预测软包排序 |
| OCV 曲线差异 | RMS error, mV | 判断配平和 OCP 差异 |
| dQ/dV 峰位差异 | peak position/area/width | 判断平台和相变差异 |
| 倍率保持率 | Q_1C / Q_0.1C | 判断传输限制 |
| DCR 差异 | DCR_pouch - DCR_coin | 判断欧姆和极化放大 |
| EIS 参数差异 | Rohm/Rct/Warburg | 拆分阻抗来源 |
| 离散性 | CV、标准差、极差 | 判断一致性和工艺噪声 |
| reference 漂移 | 每批 G0 的指标变化 | 剔除工艺批间漂移 |

建议首轮达成以下最低判断：

1. G0 reference 软包容量 CV <= 2%，扣电容量 CV <= 1.5%。若达不到，先优化制程一致性。
2. 扣电全电池与软包的容量排名 Spearman >= 0.7，说明扣电具备筛选价值。
3. 扣电全电池与软包的能效排名若低于 0.5，应重点检查极片孔隙率、膜片电阻、焊接电阻、浸润和化成。
4. 若半电池排序与软包排序不一致，而全电池扣电排序一致，说明配平和全电池界面是关键。
5. 若全电池扣电排序也不一致，说明软包工艺放大项占主导，需要 DOE-II。
