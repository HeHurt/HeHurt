## 极性与域映射

二维轴对称模型从下到上的堆叠关系为：

`正极壳体 → 底部金属垫片 → Al → LFP → 隔膜 → 石墨 → Cu → 顶部金属垫片 → 负极壳体`

关键域：LFP 为域 4，隔膜为域 5，石墨为域 6，Al 为域 3，Cu 为域 7；域 11 为 PC 绝缘密封圈。顶部负极壳体边界 20 接地并固定，底部正极壳体边界 2 施加电流及机械载荷。

## 厚度参数联动

在“全局定义 → 参数”中直接修改：

- `t_ca`：正极活性层厚度；
- `t_an`：负极活性层厚度。

各层位置由以下累积关系定义：

```text
z_al        = z_stack
z_ca        = z_al + t_al
z_sep       = z_ca + t_ca
z_an        = z_sep + t_sep
z_cu        = z_an + t_an
z_stack_top = z_cu + t_cu
z_nc        = z_stack_top + t_nc_bot + t_tsp
```

因此修改 `t_ca` 会平移隔膜、负极、Cu、顶部垫片和负极壳体；修改 `t_an` 会平移 Cu、顶部垫片和负极壳体。修改后应依次执行“几何 → 全部构建”和“网格 → 全部构建”。

## 右侧密封闭合

原重建版沿用了参考参数 `W_g=1.575 mm`，但该处径向距离实际为：

```text
R_pc-R_nc_bot = 12.22 mm-10.30 mm = 1.92 mm
```

因此会留下 `0.345 mm` 的开口。修正版改为：

```text
W_g = R_pc-R_nc_bot
```

PC 密封圈右边界由此严格贴合正极壳内壁，并且仍随上方堆叠厚度通过 `z_nc` 整体平移。

## 材料与物理场

- 域 4：LFP；域 6：Graphite；域 5：LiPF6 电解液；
- 域 3：Al；域 7：Cu；壳体、垫片和弹性导电件：Structural steel；密封圈：Polycarbonate；
- LFP 弹性模量采用参考模型的 `1.178 GPa`；
- 保留锂离子电池、固体力学、接触电阻、局部压力—孔隙率反馈和嵌锂呼吸表达式，并重绑到上述正确域。

## 网格

Al/LFP/隔膜/石墨/Cu 五层采用映射网格，其余结构采用自由三角形网格。闭合修正版总单元数为 1970，避免自动网格在微米薄层中生成数万个单元。
