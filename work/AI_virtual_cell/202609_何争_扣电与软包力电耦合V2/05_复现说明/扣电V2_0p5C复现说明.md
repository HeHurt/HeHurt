# 扣电 V2 0.5C 完整循环复现说明

## 文件

- 已计算模型：`02_模型/扣电_V2_正确极性_0p5C_100N完整耦合_已计算.mph`
- 模型配置脚本：`99_内部文件/脚本/配置扣电V2_0p5C完整耦合.py`
- 探针修复脚本：`99_内部文件/脚本/修复扣电V2_端电压探针.py`
- 完整循环脚本：`99_内部文件/脚本/运行扣电V2_0p5C完整循环.py`
- 结果提取脚本：`99_内部文件/脚本/提取扣电V2完整循环结果.py`
- 绘图与 Excel 脚本：`99_内部文件/脚本/绘制扣电V2完整循环结果.py`

## 运行顺序

1. 使用 COMSOL 6.4 打开计算版模型或通过 `sim` 的 COMSOL no-GUI 会话加载模型。
2. 运行完整循环脚本，时间列表为 `range(0,60,18000)`。
3. 确认解 `sol3` 最终时间为 18000 s，并保存已计算模型。
4. 运行结果提取脚本，内部 CSV 写入 `99_内部文件/中间数据`，JSON 写入 `99_内部文件/JSON`。
5. 运行绘图脚本，正式图和汇总工作簿写入 `04_输出结果`。

## 验收点

- `i_1C=0.016398503865 A`，0.5C 电流为 `0.008199251933 A`。
- 正极端电流边界、端电压探针和电流探针均为边界 2；接地边界为 20。
- 正极/隔膜/负极域分别为 4/5/6，铝箔/铜箔域分别为 3/7。
- `sol3` 含 307 个输出时刻，首末时刻为 0/18000 s。
- 充电截止事件约为 7115.7 s，放电截止约为 14707.0 s。
- 正式输出应包含 8 张 PNG 和 `扣电V2_0p5C完整循环结果汇总.xlsx`。
