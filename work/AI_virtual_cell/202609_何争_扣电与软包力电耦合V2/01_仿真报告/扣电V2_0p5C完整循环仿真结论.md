# 扣电 V2 0.5C 完整循环仿真结论

## 1. 模型状态

- 几何沿用用户确认的“正确极性、参数化闭合堆叠”版本，本次未修改几何尺寸或拓扑。
- 正极为 LFP 域 4，隔膜为域 5，负极石墨为域 6；铝箔为域 3，铜箔为域 7。
- 上部负极壳接地边界为 20，下部正极壳电流端边界为 2；端电压与电流探针均绑定到边界 2。
- 机械场覆盖壳体、密封圈、正负极、隔膜及铜铝箔；固定边界 20，100 N 载荷施加于边界 2。
- 开启局部压力—孔隙率反馈和非线性嵌锂呼吸：`coupling_on=1`、`local_porosity_on=1`、`breathing_on=1`、`breathing_mode=2`。
- 活性层采用映射网格，壳体/密封圈采用自由三角形网格，共 1966 个单元。最小网格质量约 0.00369，完整瞬态能够收敛，但局部应力峰值仍需按网格敏感性结果解释。

## 2. 0.5C 循环结果

工况为初始 SOC 1%、100 N、0.5C 恒流充电至 3.65 V、静置 600 s、0.5C 恒流放电至 2.50 V、再静置至 18000 s。扣电自身 `i_1C=16.3985 mA`，因此 0.5C 电流为 8.1993 mA。

| 指标 | 结果 |
|---|---:|
| 充电截止时间 | 7115.72 s（1.977 h） |
| 放电开始时间 | 7718.72 s（2.144 h） |
| 放电截止时间 | 14706.99 s（4.085 h） |
| 充电容量 | 16.207 mAh |
| 放电容量 | 15.916 mAh |
| 库仑效率 | 98.21% |
| 能量效率 | 95.66% |
| 最大库仑积分 SOC | 99.83% |
| 循环末端 SOC | 2.77% |
| 60 s / 最终静置回弹 | 344.4 / 422.7 mV（相对最后一个放电输出点） |

事件求解器在 7115.7 s 正常触发充电截止。放电末端最后一个保存输出点为 2.4765 V，略低于 2.50 V 事件阈值，这是事件附近输出离散造成的记录差异；若相对 2.50 V 截止值计算，最终静置回弹约为 399.2 mV。

## 3. 电化学结果解释

1. 石墨平均嵌锂比例在 0.0591–0.9205 之间变化；LFP 平均嵌锂比例在 0.9902–0.0210 之间变化。充电时石墨嵌锂、LFP 脱锂，放电时方向相反，正负极极性和 SOC 映射方向正确。
2. 径向方向的大部分活性区嵌锂状态较均匀，主要非均匀性集中在极片外缘；厚度方向两侧界面差异明显。例如充电 SOC 90% 时，LFP 铝箔侧平均 θp≈0.318，而隔膜侧约 0.011；石墨铜箔侧平均 θn≈0.763，而隔膜侧约 0.955。说明该模型的主要反应不均匀性来自厚度方向传输，而非主体径向梯度。
3. 全域电解液浓度最大跨度达到 909.7 mol/m³，且在充放电末端显著增大；接触压降最大仅 0.125 mV。因此本工况的电压滞回和末端回弹主要由浓差/反应极化及截止后浓度松弛控制，当前接触电阻不是主导项。
4. 充电和放电同 SOC 下，集流构件电流密度形态近似镜像且对 SOC 不敏感，符合恒流边界特征；高电流密度集中在薄集流体、壳体传导通路和斜向连接区域。SOC 50% 时中位电流密度约 26 A/m²，99% 分位约 2067 A/m²，最大约 2143 A/m²。

## 4. 力学与双向耦合结果解释

1. 石墨最大非线性呼吸应变约 4.99%，LFP 最大收缩应变幅值约 0.60%；加载边界在完成 100 N 预压后的循环相对位移幅值约 38 μm。
2. 三层区域平均压缩压力峰值约 0.313 MPa；最小孔隙率为 0.2916。区域平均孔隙率随循环变化不大，是因为压力反馈系数较弱且平均值稀释了局部变化，并不代表空间场没有变化。
3. 径向分布显示极片外缘附近局部压力达到模型中 2 MPa 的限幅值，对应孔隙率明显降低；主体区域压力远低于边缘。这一高值受闭合壳体、材料刚度突变、尖角/接触附近应力集中和网格质量共同影响，适合用于定位热点，不宜直接当作已校准的真实接触压力。

## 5. 验收结论与建议

当前模型已经完成“正确极性几何 + 电化学 + 100 N 力学 + 局部压力—孔隙率反馈 + 非线性嵌锂呼吸 + 事件控制完整循环”的闭环计算，端电压、SOC 方向、循环切换和空间后处理均可读。

后续若用于定量设计，建议优先做两项校准：

1. 对活性层厚度方向再细化网格并做网格独立性检查，确认界面嵌锂梯度和外缘 2 MPa 压力限幅区是否稳定。
2. 用压缩试验标定密封圈/极片等效模量及压力—孔隙率系数，用 EIS/DCR 或脉冲数据标定接触电阻；否则力学热点和接触压降只能视为机理趋势。
