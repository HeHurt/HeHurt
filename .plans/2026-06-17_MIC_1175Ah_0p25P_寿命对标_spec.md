# MIC 1175Ah 0.25P 寿命对标 Spec

## 目标
将 MIC 1175Ah 0.25P 循环寿命 Excel 整理为可复用的模型对标数据，并建立 25°C / 45°C 老化仿真与实测对标的固定 notebook 流程。

## 输入
- 参数文件: `params/paramsMIC.py`
- 实验数据: `data_raw/MIC_1175Ah/Hithium_TI_∞Cell 1175Ah_循环寿命 Cycle Life_20260523_V1.1(45℃循环预测曲线调整).xlsx`
- 实验 sheet: `0.25P`
- 工况: 25°C 0.25P、45°C 0.25P
- 实测曲线: 每个温度 2 颗 cell；sheet 内另含预测保持率辅助曲线

## 预期输出
- `.dat`: 统一长表，保留 cell 级实测、温度均值曲线和可选预测曲线
- Notebook: MIC 1175Ah 专用 0.25P 循环老化对标 notebook
- 图表: 容量保持率、能量效率对标；仿真容量/ SOH 曲线；可选产热和深度分析
- Excel: 仿真循环指标导出到 notebook 输出目录

## 对标口径
- 实测容量保持率同时保留:
  - `capacity_retention_nominal = discharge_capacity_ah / 1175`
  - `capacity_retention_bol = discharge_capacity_ah / q_bol`
- 默认对标使用 `capacity_retention_bol`，避免 1175Ah 标称归一导致首圈保持率约 1.03-1.04，与仿真首圈归一口径不一致。
- BOL 取每条实测曲线的放电容量峰值；峰值前爬坡圈不删除到源数据之外，但 loader 默认输出 BOL 对齐后的 cycle。

## 约束
- 求解器: `IDAKLUSolver` 优先
- 模型: DFN + OKane2022 降解基座 + `paramsMIC`
- `var_pts`: `{"x_n": 5, "x_s": 5, "x_p": 5, "r_n": 20, "r_p": 20}`
- 每个温度必须重新创建 `pybamm.ParameterValues("OKane2022")` 并 update MIC 参数，避免参数污染
- Notebook 复用 `BatteryProject/src` 既有函数，不在 notebook 中重复实现数据解析、P-rate 换算、循环指标导出等逻辑
