# .plans — Spec/Plan 沉淀机制 Harness

## 这个区域是什么
存放任务规格(spec)和实施计划(plan)。当一个仿真任务足够复杂时（涉及多温度、多电芯、多工况），先在这里写一份 spec/plan，再动手执行。

## 什么时候需要写 spec/plan
- 涉及 **3个以上温度 × 3个以上SOC** 的矩阵扫描
- 需要 **新建或大改参数文件**
- 需要 **修改 3 个以上代码文件**
- 周期超过 **1 天** 的老化仿真方案设计
- 任何对标实验数据的方案（需记录数据来源）

## Spec 模板
```markdown
# [任务名] Spec

## 目标
一句话说清楚这个仿真要回答什么问题。

## 输入
- 参数文件: paramsXXX.py
- 实验数据: 来源、路径、格式
- 工况范围: 温度、倍率、SOC、循环数

## 预期输出
- 图表: 什么图、多少张
- Excel: 导出路径、sheet 结构
- 指标: RRMSE 目标、容量保持率等

## 约束
- 求解器选择
- var_pts 配置
- 运行时间预估
```

## Plan 模板
```markdown
# [任务名] Plan

## 基于 Spec
链接到对应 spec 文件。

## 步骤分解
1. [ ] 步骤1 — 预计修改哪些文件
2. [ ] 步骤2
3. [ ] ...

## 验证标准
- 每个步骤完成后如何验证
- 最终交付物清单
```

## 文件命名
```
.plans/
├── AGENTS.md           ← 本文件
├── 2026-04-13_MIC峰值电流扫描_spec.md
├── 2026-04-13_MIC峰值电流扫描_plan.md
├── 2026-04-10_314老化建模_spec.md
└── ...
```

## 沉淀规则
- 每次完成复杂任务后，如果过程中发现有价值的模式，更新对应区域的 AGENTS.md
- spec/plan 完成后不删除 — 这是项目的「仿真记忆」
- 计划变更时在 plan 文件中追加变更记录，不覆盖原文
