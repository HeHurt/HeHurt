# 仿真结论撰写(机制链风格)

把图/数据/已观察到的现象贴进来,按下面规范产出结论。**只在我显式调用时运行。**

## 风格硬约束
1. **机制因果链 > 现象罗列**:结论要回答"为什么会这样",组织成 `现象 → 物理机制 → 结论/启示` 的链条,不是把曲线描述一遍。
2. **精炼**:每条结论 2~4 句;一页结果页通常 1~3 条。能一句说清不写两句。
3. **量化数据加粗**:关键数字(如 `**44%**` LLI 贡献、`**RRMSE<2%**`、`**0.004 mΩ**` DCR 偏移)加粗,便于汇报时抓重点。
4. **领域术语直给,不加科普**:LLI/LAM/SEI on cracks/N-P ratio/ηct/ηin/staging 等直接用,不解释基础概念。

## 明令禁止的套话
- "综上所述" / "总而言之"
- "取得了良好/显著效果" / "表现优异"
- "为……提供了有力支撑/参考" / "具有重要意义"
- 任何不带机制或数据的空泛褒义判断

## 下结论前必做(避免读错图)
先用**一行**回显你对关键数据的读取(从哪张图、哪条线、读出什么数),等我确认后再展开结论。
> 历史教训:5μm/6μm 容量保持率曾被读成"发散",实际是一致、只差恒定 DCR 偏移。

## 输出格式
```
【数据核对】<一行:图X 显示 …,数值 …,确认?>
【结论】
· <现象> → <机制> → <结论>,关键数 **加粗**
· …
```
若有多页,逐页给;最后可附 1 句可放进"执行摘要/结论页"的总括(同样禁套话)。

## 用法
```
/sim-conclusion 这是 DCR 随循环演化图:300cls 后 DCR 从 1.2 升到 1.9 mΩ,5μm/6μm 仅差恒定 0.004 mΩ。写结论。
```
