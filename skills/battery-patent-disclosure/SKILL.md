# 电池方向专利技术交底书生成 (Battery Patent Disclosure)

为电池研发发明生成一份**可直接提交的中文专利技术交底书**。版式唯一真源为 `E:\Downloads\专利模板` 中的海辰官方模板；必须先复制对应模板，再在副本中填写和编辑，禁止从空白文档或 `build_jiaodishu.js` 自行创建交底书版式。附图数量、类型和插入位置按方案表达需要确定，不机械限定为 5 张。

## 官方模板（强制）

模板目录：`E:\Downloads\专利模板`

| 发明类型 | 必须使用的模板 | 典型范围 |
|---|---|---|
| 机械/结构/制造 | `海辰技术交底书模板（机械）.doc` | 电极、极耳、焊接、卷绕、注液结构、电芯结构、设备及制造工艺 |
| 化学/材料/配方 | `海辰技术交底书模板（化学）.doc` | 化合物、活性材料、电解液、配方、材料制备及表征测试 |
| 软件/方法 | `海辰技术交底书模板（软件）.doc` | 仿真方法、算法、BMS、寿命建模、数据处理、软件系统 |
| 外观设计 | `海辰技术交底书模板（外观）.doc` | 产品整体或局部外观设计 |

执行规则：
1. 模板原件只读，不得覆盖或改名。
2. 每次任务先把匹配模板复制到任务工作目录，再编辑该副本；不得创建空白 Word 后仿制模板。
3. 默认可将工作副本另存为 `.docx` 便于编辑和交付，但该 `.docx` 必须由模板副本转换而来，并保留模板的页面设置、标题、表格、栏目层级和修订履历。
4. 不能确定模板类型时，按主要保护对象选择；跨类型方案不得自行拼接两套模板，必要时先向用户确认。
5. 若模板目录不存在、模板打不开或 DLP 无法解密，立即停止文档制作并说明问题；不得回退到自建版式。

## 工作流程（按顺序执行）

### 0A. 批量头脑风暴 / 候选初筛入口
当用户说"帮我想几个专利"、"再多想一些结构/工艺类"、"先初筛一遍"、"去掉拥挤度高的"时,不要直接写交底书。先输出候选池:

1. 按方向分组: 结构、工艺、测试/诊断、仿真/算法、BMS/运维。
2. 每个候选给: 核心发明点、可保护对象、为什么适合海辰长时储能、可能相近技术、拥挤度初判(高/中/低)、建议下一步。
3. 优先推荐"问题真实、可测可验证、结构或流程边界清楚、与长时 LFP/石墨厚电芯相关"的方向。
4. 对拥挤度高的候选,只保留差异化切入点;不要把普通注液、常规压力管理、泛泛 AI 预测写成强候选。
5. 用户选定某个候选后,再进入 Step 0/1 的正式交底书与 prior-art 初筛流程。

批量查新时,先生成脱敏中文检索式、关键词组合、分类号和候选排序表;只有用户提供度衍导出或授权后,才分析具体度衍结果。

### 0. 判定类型并复制官方模板
先按主要保护对象判定为**机械/结构/制造类、化学/材料/配方类、软件/方法类或外观设计类**，再从上表选择对应官方模板并复制到任务工作目录。后续所有写作都在该副本上完成。软件/方法类需要做客体合规处理（见策略参考）。不要自行增加官方模板没有的标题副标注；如确有必要，只能在不改变模板固定栏目和版式的前提下写入提案名称或正文。

### 1. 先做现有技术初筛（先读 `references/prior_art_screening.md`）
**动笔前先跑一轮 prior-art 初筛，尤其是用户提到"查重/查新/度衍/重复专利/FTO"时必须执行。** 按 `references/prior_art_screening.md` 处理：先生成脱敏检索式、分类号和中英文关键词；再根据可用条件选择公开 web 检索、度衍官方 API（仅在用户提供授权和文档时）、度衍浏览器半自动检索或度衍导出结果分析。对话里给用户：**拥挤度（高/中/低）+ 命中的相近在先技术（paraphrase 并引用来源）+ 差异化建议 + 可直接粘进度衍的中文检索式与分类号**。命中过近时，先和用户确认是否**调整切入点或换方向**，再决定动笔；决定写时把最接近对比文件与差异点喂进"现有技术/缺陷"铺垫与"改进点"，使权利要求落在空隙上。固定提示三条：**初筛非正式 FTO、度衍/中文库需复核、非法律意见**。

### 2. 策略与可行性判断（先读 `references/strategy_and_eligibility.md`）
**动笔前**先快速判断可行性、定下权利要求策略，并在对话里给用户一段简短的可行性说明。要点（细节见参考文件）：
- 优先**结构权利要求**（拆解/CT 可见可测，比纯算法强）；
- 机理方向有争议时用**功能性/目标导向**的权利要求措辞；
- 软件/方法类必须**绑定硬件 + 技术问题 + 技术效果**以越过中国"智力活动规则"客体门槛，并配套**系统 + 计算机可读存储介质**权利要求；
- 把"**设计判据（仿真给出）**"与"**受保护对象（落入界定范围的结构）**"切分开——保护结构，不保护算法；
- 收尾务必提示 **FTO（自由实施）检索**、参数为**示意值需仿真/实测标定**、以及**非法律意见**。

### 3. 先读 documents 技能并检查模板副本
编辑 Word 前先读当前环境的 `documents` skill。检查模板副本的文件头、可打开性、页面设置、固定表格、栏目和修订履历；确认它确实来自官方模板后再写入内容。

### 4. 按需要生成附图（先读 `references/figure_guide.md`）
附图数量由完整说明技术方案所需的信息决定，不固定为 5 张。机械模板通常至少包括结构立体/俯视、剖面或局部放大、关键机理/对比以及制造流程；软件模板通常包括应用设备、流程图和系统架构图；化学模板按需要提供工艺、表征和性能数据图；外观模板按官方视图要求提供图片或照片。
- 专利附图原则上采用清晰的黑白线条图，数字标号与正文一致；确需用颜色表达仿真云图或实验数据时，另提供可黑白辨识的线型、纹理或灰度编码。
- **每张图生成后必须 view 检查**并修正标注重叠、箭头方向、缺字形、裁切和黑白打印辨识度。

### 5. 在官方模板副本中填写
使用 Word COM、`python-docx` 或 OOXML 对模板副本做局部填充和必要扩展。保留官方页面设置、固定标题、基本信息表、栏目层级和修订履历，不得用 `assets/build_jiaodishu.js` 重建正文。
- 将联系人、提案名称、技术领域和创新方式填入模板原有基本信息表。
- 用正式内容替换模板方括号中的撰写提示；不要把无关提示残留在交付稿中。
- 只有一个完整技术构思时，仅保留并填写方案 A；删除空的 B/C 提示段，并将“改进后的技术效果”顺延为下一节。只有存在真实、可实施且具有独立技术特征的拓展方案时，才填写 B/C，不得为凑模板虚构拓展。
- 化学模板严格按其 3.1 至 3.6 栏目填写，必选项不得省略；外观模板按其图片/照片与视图栏目填写。
- 新增图、表、定义说明或实施例时，只在对应官方栏目内扩展，不另造一套目录结构。

### 6. 校验与预览
- 结构校验：确认文件仍含所选模板的基本信息表、固定栏目和修订履历，且未混入其他类型模板的栏目。
- 内容校验：逐项核对必选内容、图号/标号、正文引用、表格、方案编号和技术效果因果链。
- 视觉校验：按 `documents` skill 将最终文件渲染为逐页 PNG，检查**全部页面**的重叠、裁切、表格断裂、空白页、字体缺失、图文错位和黑白打印辨识度；发现问题必须修改并重新渲染。

### 7. 交付
`present_files` 输出 `.docx`。若执行了初筛，另输出或在对话中给出 `prior_art_search_queries.md`（度衍检索式/分类号/关键词）和 `查新风险初评.md`（相近文件、差异点、风险等级）。对话里给：简短的设计亮点说明 → FTO/参数示意/非法律意见三条提示 → 主动提出可展开为**权利要求草稿**。

## 模板结构（完整规范见 `references/template_structure.md`）
栏目以所选官方模板为准。机械与软件模板采用“一、基本信息／二、技术内容／1 现有产品技术情况／2 技术缺陷或问题／3 详细技术方案／4 发明构思总结／修订履历”；化学和外观模板使用各自专用栏目，不得套用机械模板结构。

## 关键约定 / 已踩过的坑（不要重新学）
- **动笔前先做现有技术初筛**（见 `references/prior_art_screening.md`）；用户提到度衍/uyanip/查重/查新/FTO 时必须执行；命中过近先与用户确认是否调整切入点或换方向，避免写一份注定撞车的交底书。
- **度衍接入不要臆造 API**：只有用户提供官方 API 文档/授权时才调用 API；否则用脱敏检索式 + 浏览器半自动检索或人工导出结果分析。不要绕过登录、验证码、频率限制或批量抓库。
- **保密优先**：未申请前不要把完整技术交底书上传第三方平台；优先用关键词、分类号、核心特征组合等脱敏检索式。
- **3.4 技术效果必须写成推理链**"①因…→因此…"，不能只下结论（模板明确要求"有理有据、切忌只下结论而无分析"）。
- **方案 A = 最优方案；B、C 仅在确有独立拓展构思时填写。只有一个想法就只写 A，不为凑格式虚构 B、C。**
- **附图**：纯黑白；写 `dV/dQ` 不要用 Unicode 上标减号（`⁻` 字体缺字形）；下标用 mathtext `$_0$`；箭头方向 = `annotate(xy=箭头头, xytext=箭尾)`（流程图向下别画反）；标题用 `pad`/`ylim` 与图形拉开；曲线易挤就用上下分栏；**每张图都要 view 后修**。
- **Word 版式**：页面、页边距、字体、表格宽度、合并关系和修订履历均继承官方模板；不得用硬编码版式参数覆盖模板。
- **3.1 里把"设计判据（仿真）"与"受保护对象（落入界定范围的结构）"分开写**，保护结构不保护算法。
- 对话**结尾固定给三条**：FTO 检索、参数为示意需标定、非法律意见。
