## 总体定位

该模板是电芯测试/仿真报告模板，适合短期性能、长期性能、安全性能三类报告页。页面风格是白底工程报告页 + 蓝色 VI 页眉页脚 + 中部图表/照片 + 顶部小结 + 底部 Test Condition。

不要把原文件中的样例曲线和照片固化为模板资产。可复用资产只有：封面浅蓝几何背景、CCC 图形、HITHIUM logo、章节页六边形、电芯示意图，以及可选的 Sample/Base 图例。

## 页面规格

- 页面比例：16:9 宽屏。
- 页面尺寸：13.333 in × 7.5 in。
- 单位：本规范中的坐标均为 inch，左上角为 `(0, 0)`。

## 内容页要求

原文件包含的报告结构：

1. 短期性能
   - 能效&容量
   - 倍率
   - SOC-OCV
   - DCR
   - 高低温
   - 5℃+低温适应性
   - 45℃+高温适应性
   - 功率特性
2. 长期性能
   - 循环：`0.5P@25℃ 100%DOD`
   - 存储：`25℃ 100%DOD`
3. 安全性能
   - 过充
   - 过放
   - 热失控
   - 挤压
   - 短路

每个内容页应至少包含：
- 标题
- `小结：`
- 主图/图组/照片
- `Test Condition:`
- 页眉 logo、页脚机密标识、页码

## 图表风格

样例图表显示出以下规则：
- 白底图、浅灰网格、黑红对比。
- Base 通常用黑色，Sample 用红色。
- 柱状图使用黑/红实心柱；折线图使用黑/红线和点。
- 图标题使用英文，坐标轴单位明确。
- 图导出比例接近 3:2，插入后不要拉伸变形。
- 原图建议宽度不低于 700 px；PPT 中常见图像源尺寸约 `711×475 px`。

## 后续生成注意事项

- 常规页的右上 HITHIUM logo 和左上 CCC 图形来自母版，不要误用内容页中的 `Sample/Base` 图例。
- `小结：` 是正文结论，不是装饰标题；需要根据仿真/测试结果重写。
- `Test Condition:` 中的测试步骤应尽量压缩为一段，不要让文字压住页脚。
- 原模板偏工程测试报告，不适合做营销式大图封面或卡片式 dashboard。
- 若使用 `PptxGenJS`，可按 `report_ppt_template_20240910_spec.json` 中的坐标直接复刻。
- 若使用 `python-pptx`，可加载原始 PPTX 或按 JSON 重建母版元素；图片资产从 base64 JSON 解码。
