# 海辰电池仿真 PPTX

## 职责与工具

- 只负责汇报结构、版式、图表嵌入、表格和视觉校验，不执行 PyBaMM/COMSOL 仿真。
- 需要撰写结论时调用 `sim-conclusion`；结论可融入图旁标注、关键数字或页面总结，只有决定使用结论框时才按本 skill 的结论框样式排版。
- 优先使用公共 Presentations 工具；已有任务若沿用可运行的 PptxGenJS 或 python-pptx 管线，也可继续使用。
- 用户提供的现成模板或新截图优先于本默认规范。
- 先根据材料决定最清楚的叙事和版面，再选择是否采用下列组件；不要为了满足格式清单牺牲信息层级、图表可读性或视觉发挥。

## 默认视觉基线

以下规则用于保持整体风格一致，但不是要求每页机械套用同一结构。可根据内容选择、组合或省略版式组件；只有 logo 禁用、用户明确指定的字体字号与颜色层级需要持续遵守。

### 页面与 logo

- 默认使用白色背景，保持紧凑、清晰的技术汇报风格。
- 不生成、不重绘、不插入海辰或 CCC logo；原本预留的 logo 区域保持空白。
- 不使用深色封面、深色结论页、深色结论条、彩色卡片或装饰性背景。

### 字体、字号与行距

- 中文统一使用 `Microsoft YaHei`（微软雅黑）；缺字时回退 `Noto Sans CJK SC`。
- 正文统一为 `12 pt`。
- 页面标题、分区标题、图标题、表头和结论文字统一为 `14 pt`。
- 全文统一使用固定值 `20 pt` 行距；段前、段后默认设为 `0 pt`，避免额外空白破坏对齐。
- 除非原始数据图自身已有必要的小字号坐标轴标签，不要擅自缩小正文来塞入更多内容；内容过密时优先拆页或精简文字。

### 项目符号

- 页面顶端的测试工况、总说明或引导文字使用加粗空心方形项目符号 `□`；项目符号本身加粗。
- 每个图、示意图或局部结果分区的标题使用箭头项目符号 `➢`。
- 不使用红色数字圆点、普通实心圆点或装饰性编号替代上述两类符号。

### 颜色与强调层级

| Token | 用途 | 默认值 |
|---|---|---|
| `accentBlue` | 首选重点色、分隔线、关键数字 | `#1E63F3` |
| `tableHeaderBlue` | 常规结果表表头底色 | `#5B9BD5` |
| `red` | 与蓝色重点有明确语义差异的异常、风险或反向指标 | `#C8102E` |
| `textDark` | 正文和边框 | `#000000` |
| `white` | 页面、表格正文和结论框底色 | `#FFFFFF` |

- 重点内容优先使用蓝色加粗。
- 只有当信息必须与蓝色重点形成明确区分时才使用红色，例如异常、风险、恶化值或反向变化；红色同样加粗。
- 同一页不要让蓝色与红色争夺主次；没有明确对立语义时只用蓝色。
- 不使用 amber、渐变、阴影、发光或高饱和多色装饰。

## 内容页版式

按以下顺序组织典型结果页：

1. 顶部放一行或两行工况信息，以 `□` 开头；信息较多时使用竖线 `|` 分隔。
2. 中部按内容排成 2–3 个结果分区；每个分区标题以 `➢` 开头。
3. 图、示意图、关键数字和短说明尽量在各自分区内对齐；避免卡片化堆叠。
4. 页面需要集中收束结论时，可在底部放结论黑框表格；若标题、关键数字、图旁标注或页面结构已经足够清楚，则省略结论框。

单页放不下时拆页，不通过缩小字号、压缩行距或遮挡图表来强行容纳。

## 两类表格

### 常规结果表

常规对比、参数、计算结果或路线展示表使用以下样式：

- 表头填充 `tableHeaderBlue`，表头文字使用白色、微软雅黑、`14 pt`、加粗。
- 正文单元格使用白底、黑字、微软雅黑、`12 pt`、固定 `20 pt` 行距。
- 网格线使用浅蓝色细线，颜色与表头蓝协调；不使用黑色粗网格。
- 普通文本左对齐；短标签和数值可居中，但同一列必须保持一致。
- 最终结果、当前采用方案或需要落地的末行使用黑色加粗正文；必要时再对其中关键值使用蓝色加粗。
- 不使用斑马纹、圆角、阴影或渐变。

### 结论黑框表格

- 只在结论框能帮助读者快速收束信息时使用，不把它作为每页必备元素。
- 结论区使用白底、黑色细边框的两列表格；左列窄、右列宽。
- 左列填写与当前内容匹配的短标签，例如“仿真结论”“机理分析”“分析结论”；一般不超过 `4` 个汉字，不固定写成“结论”。
- 左列标签使用微软雅黑、`14 pt`、加粗、水平与垂直居中。
- 右列逐条填写结论，每条可用 `➢` 开头；使用微软雅黑、`14 pt`、固定 `20 pt` 行距。
- 结论中的关键结果优先使用蓝色加粗；只有需表达异常、风险或反向变化时才使用红色加粗。
- 不给结论框添加深色填充、彩色标题条、圆角、阴影或额外装饰。

## 报告结构

按材料多少选择最小必要页数，常用骨架如下：

1. 封面或主题页：白底，标题与必要的项目号/日期，无 logo。
2. 背景与目标：说明问题和判断目标。
3. 方法与工况：展示模型、protocol 和边界条件。
4. 结果页：围绕图表、关键数字和必要说明自由组织；可有多页，结论框按需添加。
5. 汇总结论页：仅在确有独立总结需要时设置；若使用结论框，采用白底黑框样式，不切换为深色页面。

单页汇报根据内容自由组织；“顶部工况 + 中部结果 + 底部结论框”只是可选结构，不是固定模板。

## 出图与嵌图

1. matplotlib 出图使用 `dpi >= 200`，中文使用 `Microsoft YaHei` 或 `Noto Sans CJK SC`，避免方块字。
2. 源图存在多余标注或边框时，先用 PIL 裁剪再嵌入。
3. 对比类数据优先使用 PPT 原生表格，保证清晰和可编辑。
4. 保持图像原始比例，不拉伸；必要时裁剪留白。
5. 图标题统一放在图上方并以 `➢` 开头，不把标题烘焙进图片。
6. stat、表格、图中标注和结论里的同一数值必须一致。

## 旧模板资源

`references/report_ppt_template_20240910_*` 为旧企业模板提取物。默认不要读取或使用其中的 logo、深色背景、旧配色和旧结论条；只有用户明确要求恢复旧模板时才参考。
